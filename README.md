## WordPress 到底需要什么配置的服务器

WordPress 官方推荐 PHP 7.3+ 和 MySQL 5.6+，这个门槛任何在售的 VPS 都能满足，真正的分水岭在内存。1 GB 内存是跑 WordPress 的底线，前提是插件装得少、不开 WooCommerce；想后台流畅、插件随便上，2 GB 起步会舒服很多。

原因不难理解：WordPress 页面要经过服务器 → PHP → 数据库 → 主题插件这条链路，PHP 进程吃的就是内存。1 GB 的机器装上 WordPress 再加 WooCommerce，内存得压到 600 MB 以内才舒服，重型插件基本要放弃。

磁盘方面反而不用焦虑：一套典型 WordPress 安装（主题加 20 个左右插件）大约占 500 MB 到 1 GB，多数内容站的实际磁盘用量不会超过 10 GB。所以选套餐时，存储是次要指标，内存和流量才是。
